# Statur Reputation System

## Overview
Statur is a reputation model for the Cardano ecosystem that encourages positive behavior through transparent, verifiable reputation scoring. This repository contains public documentation, milestone outputs, and will include open-source components and libraries as the project develops.

## Repository Contents

### Catalyst Milestone Documentation
Documentation and deliverables for the Project Catalyst funded milestones:

- **Fund 12 Milestone 2**: NFT and reputation contract development, karma algorithm, staging app, backend API, badges, and Figma design
