# 1️⃣ Architecture, Initial Data Collection Research, UI/UX Design, initial PoC

## 💡 Purpose
This document outlines the goals and outcomes of Milestone 1 of the Catalyst Fund 12 project "Iagon: Statur - Reputation Model for Cardano Ecosystem that encourages positive behavior" (further referenced to as Statur).

It starts with the project ID, project and milestone links, the outputs, acceptance criteria and proposed evidence for the Proof of Achievement in the milestone module. After that follows a results section that includes the evidence, links, explanations, and supporting documentation.

## 🆔 Project ID
`1200130`

## 🔗 Important Links

- Catalyst: <https://projectcatalyst.io/funds/12/cardano-use-cases-product/iagon-statur-reputation-model-for-cardano-ecosystem-that-encourages-positive-behavior>
- Milestone Module: <https://milestones.projectcatalyst.io/projects/1200130/milestones/1>

## 🧱 Milestone Outputs
- High Level Architecture and Research Documentation
- Research on qualitative and quantitative reputation metrics
- Data collection mechanism Research and PoC
- Initial design UI/UX components for the system
- PoC to display sample example metrics for a single project
- Plan contracts development

## 📦 Deliverables
1. High Level Architecture and Research Documentation
2. List of possible metrics on documentation
3. Initial Figma UI/UX for the system
4. PoC with mechanism on how data was collected, and the reputation score for users from the single project
5. Contracts high level architecture

## ✔ Acceptance criteria
- Documentation of the project requirements and objectives completed. The documentation will be comprehensive, easy to understand, and accessible to both technical and non-technical community members.
- Initial Figma design
- Finalised user score Metrics documentation
- Database schema designs
- Contract detailed design
- Data collection based on the developed sql views

## 🧾 Evidence of milestone completion
- Documentation about requirements and objectives are published and updated on the Iagon website along with metrics formula for score calculation
- Figma prototype file
- A publicly viewable POC app deployed with scores based on the Iagon
- Video demo

### PoC to Display Example Metrics for a Single Project (Iagon)
A working proof-of-concept application deployed on staging that demonstrates reputation score display using real Iagon user data. The PoC showcases the frontend interface for viewing scores, and metrics breakdown.

Links:
- [Live PoC Application (Beta)](https://statur-beta.iagon.com)
- [Video Demo](https://youtu.be/sk7IgSupYcs)

### Plan Contracts Development
High-level architecture for smart contracts covering non-transferable (soulbound) reputation NFTs following CIP-68 standards. The contracts handle minting of reputation tokens, on-chain credential storage, and verification mechanisms. Initial contract drafts have been submitted for security audit (audit is delivered in a follow-up milestone).
